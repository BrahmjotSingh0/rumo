# Code of Conduct

## Our standard

Be respectful. Disagree about code and decisions as much as you like, don't attack people. That covers most of it, but concretely:

- No harassment, insults, or personal attacks, in issues, PRs, discussions, or anywhere else related to this project.
- No discriminatory language or behavior based on someone's identity, background, or experience level.
- Assume good faith. Most confusing questions and clumsy first PRs come from someone still learning the codebase, not from bad intent.
- Keep technical disagreements technical. "This approach has a race condition" is fine. Anything aimed at the person instead of the code isn't.

## Scope

This applies to any space where you're representing this project: issues, pull requests, discussions, and any other official channel that comes up later.

## Reporting

If someone's behavior violates this, email the maintainer at the address listed on the [GitHub profile](https://github.com/BrahmjotSingh0), or open a private report via [GitHub's report abuse form](https://github.com/contact/report-abuse) if it's severe enough to involve GitHub directly. Reports are handled privately.

## Enforcement

Maintainers can remove comments, close issues/PRs, or block someone from the project for violating this. There's no fixed escalation ladder here, it's a small project, so it's handled case by case with judgment rather than a formal process.
